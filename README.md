# 🦈 Fin-BOARD
**Next-Gen Financial Analytics Dashboard**

Fin-BOARD is a premium, real-time financial dashboard designed for high-impact data visualization and seamless API integration.

## 🌟 Features
- **Dynamic Widget System**: Add, remove, and rearrange customizable widgets (Charts, Tables, Cards).
- **Universal API Integration**: Connect to any financial API with live testing and field mapping.
- **Advanced Visualizations**: Interactive candlestick/line graphs, market tables, and wallet analytics.
- **Premium Aesthetics**: High-end glassmorphism design with immersive dark/light modes.
- **Animated Splash Screen**: High-impact loading experience with personalized welcome animations.
- **Wallet Management**: Track balances, transactions, and account evolution in style.

## 🚀 Getting Started
1. **Clone & Install**:
   ```bash
   git clone https://github.com/Samx9x/Fin-BOARD.git
   cd groww-web_intern
   npm install
   ```
2. **Run Dev Server**:
   ```bash
   npm run dev
   ```
3. **Explore**: Open [http://localhost:3000](http://localhost:3000)

## 🛠️ Tech Stack
- **Framework**: Next.js 14 (App Router), TypeScript
- **Styling**: Tailwind CSS, Custom CSS Variables
- **Animations**: Framer Motion
- **Charts**: Recharts
- **State**: Zustand (with Persist)
- **Grid**: React Grid Layout
